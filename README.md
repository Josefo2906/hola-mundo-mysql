# Aplicación Web Hola Mundo con MySQL y Docker Compose

Aplicación web desarrollada en Python (Flask) dentro del directorio `src` que se conecta a un contenedor de base de datos MySQL 8.0 orquestado con Docker Compose.

## Ejecución

1. Construir e iniciar los contenedores:

    docker compose up -d --build

2. Abrir en el navegador:

    http://localhost:5000
